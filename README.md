 UPI Transaction Analysis
  Project Overview

This project focuses on analyzing UPI transaction data to understand transaction patterns, payment behavior, and overall transaction performance.

The data was analyzed and visualized using Microsoft Excel and Power BI to create an interactive dashboard and identify meaningful trends from the transaction data.

 Project Objectives
Analyze UPI transaction trends
Understand transaction behavior across different categories
Identify high and low transaction periods
Analyze transaction amounts and volumes
Create an interactive Power BI dashboard
Convert raw transaction data into meaningful visual insights
🛠️ Tools & Technologies
Microsoft Power BI — Data visualization & dashboard development
Microsoft Excel — Data preparation and analysis
Data Cleaning — Preparing transaction data for analysis
Data Analysis — Identifying patterns and trends
Data Visualization — Interactive charts and dashboards
